# BEAR Store — Frontend Prototype

## Development

```bash
cd bear-store
npm install
npm run dev
```

Open http://localhost:5173

## Stack

- HTML5, CSS3, Vanilla JavaScript (ES Modules)
- Vite build tool
- No frameworks

## Notes

- All data is mock/demo data
- No real authentication, orders, or payments
- Demo checkout does not create real orders or send WhatsApp messages
- Cart and wishlist persist in localStorage
